# FitPlan AI

เว็บคำนวณแคลอรี่จากคลิปออกกำลังกาย จดอาหาร และแจ้งเตือนตารางผ่าน LINE

## ฟังก์ชันหลัก

- **ให้คะแนนและวิเคราะห์ความสมดุลของตาราง** (Workout Schedule Score 0–100 แยก 5 ด้าน) พร้อม AI สรุปและแนะนำ
- **ปรับตารางอัตโนมัติเมื่อข้ามวัน** ด้วยการค้นหาวันที่ดีที่สุด (optimization) เฉพาะสัปดาห์นั้น
- **"อยากออกส่วนไหนวันนี้"** จัดท่า เซต จำนวนครั้ง และเวลาพัก ตามระดับ เป้าหมาย อุปกรณ์ และเวลาที่มี
- **หน้า "วันนี้"** บอกว่าวันนี้ต้องออกอะไร ปุ่มทำสำเร็จ/ข้าม และ streak
- **ความก้าวหน้า** บันทึกน้ำหนัก/รอบเอวรายสัปดาห์ กราฟ ตารางสรุป และ AI วิเคราะห์แนวโน้ม
- **วิเคราะห์คลิป YouTube** แยกช่วง แคลอรี่ ระดับความหนัก (เบา/ปานกลาง/หนัก) และกล้ามเนื้อที่ใช้
- คำนวณแคลอรี่ต่อวันตาม 6 เป้าหมาย, ประเมินแคลอรี่อาหารด้วย AI, แจ้งเตือนผ่าน LINE

## โครงไฟล์

```
app/
  main.py          สร้างแอปและรวม routes
  routes/          web (หน้าเว็บ+login), food, workout (วันนี้/สร้างท่า/ข้าม/ย้าย), plan (ตาราง), progress_api, cron
  calc.py          BMI / BMR / แคลอรี่ต่อวัน, ระดับผู้ใช้, เป้าหมาย 6 แบบ
  exercises.py     คลังท่า 45 ท่า, กล้ามเนื้อ, ตัวสร้างโปรแกรม
  analysis.py      ให้คะแนนและวิเคราะห์ตารางรายสัปดาห์
  optimizer.py     ปรับตารางเมื่อข้ามวัน
  planning.py      แผนรายวัน (รวมการย้ายเฉพาะสัปดาห์)
  progress.py      สรุปรายสัปดาห์และ streak
  video.py         ลิงก์ YouTube, ค่า MET, ระดับความหนัก
  ai.py            เรียก Gemini (คลิป, อาหาร, คำแนะนำ)
  migrate.py       เติมคอลัมน์ใหม่ให้ฐานข้อมูลเดิมอัตโนมัติ
tests/             pytest 128 ข้อ
```
